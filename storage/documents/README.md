# مجلد تخزين المستندات

هذا المجلد مخصص لتخزين المستندات بعد التحقق منها.

## هيكل المجلد

- documents/: المستندات الموثقة
- temp/: الملفات المؤقتة

## ملاحظات

- عند رفع مستند، سيتم تخزينه في مجلد documents/ مع اسم فريد
- سيتم حفظ معلومات المستند في قاعدة البيانات
- سيتم حذف الملفات المؤقتة بشكل دوري
