# واجهة التحقق من المستند

مشروع Node.js متكامل يحاكي واجهة التحقق الظاهرة في المراجع المرفقة، مع دعم سطح المكتب والجوال وواجهة API وقاعدة بيانات SQLite.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```powershell
npm install
npm run init-db  # تهيئة قاعدة البيانات وإضافة بيانات تجريبية
npm start
```

## النشر باستخدام Supabase

1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor والصق محتوى `db/supabase-schema.sql` ثم نفّذه.
3. أضف متغيرات `.env.example` إلى منصة تشغيل Node.js مثل Render أو Railway.
4. استخدم `SUPABASE_SERVICE_ROLE_KEY` في الخادم فقط، ولا تضعه داخل ملفات `public`.
5. شغّل المشروع بالأمر `npm start`.

عند وجود `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` يستخدم المشروع PostgreSQL وSupabase Storage تلقائيًا. وعند عدم وجودهما يستمر التشغيل المحلي باستخدام SQLite.

ثم افتح `http://localhost:3000`.

## النشر

اضبط متغير البيئة `PORT` عند الحاجة. ينشئ الخادم مجلد `data` وملف `verification.db` تلقائياً. على الاستضافات ذات القرص المؤقت، استخدم مسارًا دائمًا عبر `DATABASE_PATH`.

## API

- `POST /api/verify` — يستقبل `serialNumber` و`idNumber` و`captcha`.
- `POST /api/upload` — لرفع ملف مستند جديد
- `GET /api/documents` — لجلب قائمة المستندات
- `GET /api/document/:id` — لعرض ملف مستند محدد
- `DELETE /api/document/:id` — لحذف مستند محدد
- `GET /api/verification-attempts` — يعرض حالة وتوقيت آخر عمليات التحقق (للتطوير فقط).

## قاعدة البيانات

يستخدم النظام قاعدة بيانات SQLite لتخزين المستندات ومحاولات التحقق. يتكون من جدولين رئيسيين:

1. `documents` - لتخزين معلومات المستندات
   - `serial_number`: الرقم التسلسلي للمستند (فريد)
   - `id_number`: رقم الهوية
   - `document_type`: نوع المستند
   - `status`: حالة المستند (active, expired, revoked)
   - `created_at`, `updated_at`: تاريخ الإنشاء والتحديث

2. `verification_attempts` - لتسجيل محاولات التحقق
   - `serial_number`: الرقم التسلسلي للمستند
   - `id_number`: رقم الهوية
   - `status`: نتيجة المحاولة (success, failed)
   - `created_at`: تاريخ المحاولة

## بيانات تجريبية

عند تشغيل `npm run init-db`، يتم إضافة البيانات التجريبية التالية:
- مستند DOC001 برقم هوية 1234567890
- مستند DOC002 برقم هوية 9876543210
- مستند DOC003 برقم هوية 5555555555

## التحقق من المستندات

للتحقق من مستند:
1. أدخل الرقم التسلسلي ورقم الهوية
2. أدخل رمز CAPTCHA
3. اضغط على زر "استمرار"

سيقوم النظام بالتحقق من صحة المستند بناءً على البيانات المدخلة. إذا كان المستند موجودًا وحالة النشطة، سيتم عرض رسالة نجاح مع نوع المستند.

## رفع المستندات

لرفع مستند جديد:
1. انقر على رابط "رفع مستند" في القائمة العلوية
2. أدخل الرقم التسلسلي ورقم الهوية
3. اختر نوع المستند من القائمة
4. اختر الملف المراد رفعه (PDF أو صورة JPEG/PNG بحد أقصى 5MB)
5. اضغط على زر "رفع المستند"

سيتم حفظ الملف في مجلد `storage/documents/` وسيتم تسجيل معلوماته في قاعدة البيانات.

## عرض المستندات

لعرض المستندات المسجلة:
1. انقر على رابط "عرض المستندات" في القائمة العلوية
2. ستظهر قائمة بجميع المستندات المسجلة
3. يمكنك عرض أي مستند بالضغط على زر "عرض المستند"
4. يمكنك حذف مستند بالضغط على زر "حذف"
